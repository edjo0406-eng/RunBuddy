---
name: RunBuddy running details
description: Product direction for collecting and showing a runner's performance details.
---

Runner profile setup should let members enter their running details, and profile views should display the values they have provided.

**Why:** The user asked for running details to be present in both profile setup and a profile view so runners can share relevant training and race information.

**How to apply:** Reuse the existing running-stat fields across profile forms and views. Keep empty values hidden, and preserve the existing boundary that excludes running stats from anonymous discovery responses.
